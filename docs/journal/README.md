# Engineering journal

This is our engineering journal as one printable A4 document. It brings together what the pages in [`docs/`](../), [`src/README.md`](../../src/README.md), [`Models/README.md`](../../Models/README.md) and [`Vehicle_Photos/README.md`](../../Vehicle_Photos/README.md) record: the rules and part limits that shaped the car, why we chose each part and what it cost us, the software from the June national-round code to the v20 finals sketches, how we test on the mat and in simulation, the problems we met and how we fixed them, and where the car stands now. Every result is labelled as mat, simulation or build, and the appendices give the pin map and the parts list. Read it here: [Blue_Wave_Engineering_Journal.pdf](Blue_Wave_Engineering_Journal.pdf). The source is [`journal.html`](journal.html), printed to PDF with Chrome.
